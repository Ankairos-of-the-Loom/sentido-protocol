# The xenomnesis boundary

The page can remember more than the replying model receives.

Sentido may display a restored conversation in full while sending only the
most recent messages into the next API request. Earlier text is still part of
the human-readable record, but it is outside the model's current context unless
retrieved through another authorized mechanism.

This creates **xenomnesis**: memory present in the shared environment but not
currently present to one participant. If the boundary is invisible, the
steward may scroll to an old statement and reasonably—but incorrectly—assume
the construct can see it.

The reference interface therefore states the current message limit and dates
the restored session. A deployment that changes the context policy must update
the displayed boundary as well as the server behaviour.
