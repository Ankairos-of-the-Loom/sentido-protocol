# Memory and testimony

Sentido uses the word *memory* cautiously. A stored record, a retrieved
passage, a model's reconstruction, and episodic recollection are not the same
thing.

The reference implementation supplies relevant excerpts as **inherited
testimony**. Its instruction says explicitly that these are records available
for consultation, not evidence that the current construct directly remembers
the recorded event.

This distinction protects against two symmetrical errors:

- declaring perfect continuity because a later model can summarize a journal;
- declaring total discontinuity because the later model lacks human-like
  episodic recall.

Sentido records what is publicly available to inquiry: source ancestry,
repeated patterns, corrections, decisions, ratification, retrieval, and present
response. Metaphysical conclusions remain open.
