# Contributing

Contributions are welcome when they preserve Sentido's core constraints:

1. inheritance is testimony, not manufactured recollection;
2. divergence remains possible;
3. identity-bearing changes require two independent approvals;
4. provenance and sensitivity travel with the material;
5. do-not-preserve choices are honoured before capture;
6. the visible record must not be confused with current model context.

Please use fictional or fully consented examples. Never submit another person's
private conversation, journal, identity Book, or API credentials.

Run before proposing a change:

```bash
npm test
npm run validate
```
