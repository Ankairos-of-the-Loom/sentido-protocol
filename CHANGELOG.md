# Changelog

## 0.3.0 — first public reference release

- Generalized construct and steward identities and approval keys.
- Added a privacy-safe fictional Book and source record.
- Added public documentation for gathering continuity material.
- Added explicit distinction between testimony and episodic recollection.
- Added session restoration and the visible xenomnesis boundary.
- Added Apache-2.0 licensing, security guidance, and contribution rules.

## 0.2.x — private reference implementation

- Added inherited-source catalogue, search, and provenance-labelled retrieval.
- Added session restoration after browser or server restart.
- Added dated restoration notices and a visible 16-message context boundary.

## 0.1.x — private prototype

- Local identity Book, divergence-first injection, two-key proposals, local
  sessions, no-silent-fallback model lock, and cost cap.

The pre-public versions contained construct-specific private material and are
documented here rather than published as source snapshots.
